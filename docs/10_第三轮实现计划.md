## 二、S2 评价触发（核心，来自讨论结论）
现状问题：赞助弹窗永远优先、评分每次启动至多弹一次、且要在「赞助+评分 key 同时 true」才重置 → 评分提示频次极低 → 零评价。
改法：
- 将 sponsor 与 rate 拆成**各自独立的节流**（各自有 first-run 延迟与 hasShown 标记，互不卡顿）。
- 评分在「首次运行满 N 天且本会话未询问」时展示；展示后**不永久隐藏**，允许在每个新启动、间隔足够长（如 ≥ 若干天）后再次提醒（把「一次性 hasShown」改为「记录最近提示时间」节流）。
- 深链失败：RateModal 先深链 `ms-windows-store://review/?productid=...`，catch 后回退打开商店详情页 `webUrl`，仍失败回退 `web`；catch 分支打 `console.warn` 便于排查。
- 全程保持 `isTauri()`/`isWindows()` 门控与 `t()` 文案。
