## 二、命令注入

### 2.1 open_in_explorer（[disks.rs](src-tauri/src/commands/disks.rs#L24-L71)）
- 实现：`Command::new("explorer").arg(&path)` 或 `.arg(format!("/select,{}", path))`，`.spawn()`。
- 结论：**通过。** Rust `std::process::Command::arg` 走 `CreateProcess` 直接传参，**不经过 shell**，无 shell 转义/拼接注入面；`path` 来自前端选中的已存在文件/目录节点（`is_dir()` 判真后分支）。`/select,` 前缀仅影响资源管理器选中行为，参数即使含逗号也为功能性边缘问题，非命令注入。
- 建议（P3 可选）：调用方对 `path` 增加「必须为绝对路径」断言，作为纵深防御。

### 2.2 嵌入式 PowerShell 脚本
- `get_physical_disks`（[disks.rs](src-tauri/src/commands/disks.rs#L74-L131)）：`$disks = Get-Disk ...` 为**静态字符串常量**，经 `-NoProfile -Command <script>` 单参数传入，无任何用户输入拼接。**通过。**
- `get_disk_partition_map`（[utils.rs](src-tauri/src/utils.rs#L30-L83)）：`Get-Partition ... ` 静态常量。**通过。**
- `get_disk_number`（[utils.rs](src-tauri/src/utils.rs#L412-L451)）：`format!("Get-Partition -DriveLetter {} | ...", drive_letter)`，但 `drive_letter` 仅取**单个** `c.is_ascii_alphabetic()` 字符（先经 L421/L429 解析，L432 校验），注入面被校验封死。**通过。**

> 小结：全部 4 处命令/PowerShell 使用均非注入向量。若后续新增拼接命令，务必沿用 `.arg()` 传参（不用字符串拼接 + shell）。

## 三、路径穿越 / 越权磁盘访问

- 现状：`analyze_directory` / `expand_directory`（[scan.rs](src-tauri/src/commands/scan.rs#L17-L332)）、`get_large_items_report`（[large.rs](src-tauri/src/commands/large.rs#L15)）、`find_duplicates`、`search_files` 均接收**任意 `path`/`root_path` 字符串**，后端直接 `fs::read_dir`/`WalkDir` 递归读取，**无盘符/挂载点白名单**，能力上等于「可枚举当前 OS 用户可读的任意目录」。

- 定性：这是磁盘分析工具**设计使然**，UI 是唯一正常调用方，本身不是越权。真正的风险链是——若前端曾发生 XSS，攻击者可通过暴露的 Tauri 命令枚举任意目录清单：
  - `tauri.conf.json` 中 `app.security.csp = null`（[tauri.conf.json](src-tauri/tauri.conf.json#L23-L25)）——**未配置内容安全策略**；
  - `withGlobalTauri = true`（[tauri.conf.json](src-tauri/tauri.conf.json#L13)）——把 `window.__TAURI__` 暴露在全局，DOM 注入即可调用全部注册命令。

- **结论：存在风险（低-中）→ 修复建议（P2）**
  1. 为生产构建配置 CSP（`default-src 'self'` 等），并考虑关闭 `withGlobalTauri`（改用 `@tauri-apps/api` 模块引入而非全局注入）；
  2. 可选：在 `analyze_directory`/`expand_directory` 对 `path` 做「须落在已挂载盘/已授予目录内」校验，或使用 Tauri `capabilities`/scope 收紧命令参数。

## 四、硬链接 / 符号链接

- 硬链接去重：[scanner.rs](src-tauri/src/scanner.rs#L262-L277) 常规遍历路径用文件 ID（`get_file_id_and_links`，[utils.rs](src-tauri/src/utils.rs#L154-L232)）去重；错误恢复路径（[scanner.rs](src-tauri/src/scanner.rs#L174-L186)）同样去重。**通过**（右侧注记：两处逻辑重复，06 报告 §5.1 已记录，维护时需同步改）。
- 符号链接：
  - `WalkDir` 默认 `follow_links = false`，扫描时对符号链接**不跟随**，无无限递归；
  - `build_file_tree` 用 `fs::symlink_metadata`（[scanner.rs](src-tauri/src/scanner.rs#L415)）不跟随链接；
  - `is_ignored_path`（[utils.rs](src-tauri/src/utils.rs#L247-L277)）过滤 `/proc`、`/sys`、`/dev` 等伪文件系统。
  - **通过**。注：Windows 上指向目录的符号链接会被按「小文件」处理（显示其链接大小而非其内容），属功能性取舍，非安全问题。

## 五、正则 ReDoS

- 现状：[search.rs](src-tauri/src/commands/search.rs#L52-L55) `Regex::new(&format!("(?i){}", query))`，用户 `query` 直接进正则，仅匹配**文件名**。
- 结论：**通过。** Rust `regex` 的 `Regex` 采用 Thompson NFA 模拟，**保证线性时间匹配**，不存在经典 `(a+)+$` 类灾难性回溯；且匹配目标仅为每个文件名（长度有限）。正则表达式本身也仅在 `spawn_blocking` 内编译一次。
- 建议（P3 可选）：对 `query` 长度设上限（如 256 字符），纯属边界礼仪，非安全必需。

## 六、敏感信息

- 后端（**通过**）：`api_key` 作为命令参数进入 `get_ai_insights`（[ai.rs](src-tauri/src/commands/ai.rs#L43-L120)），仅用于 `Authorization: Bearer {...}` 请求头（L87），不落盘、不打印；仓库源码/配置无硬编码密钥（已全局检索，仅命中该 Authorization 一处）。
- 前端（**存在风险 → P2**）：[AIInsightsView.tsx](src/components/AIInsightsView.tsx#L34) 将 `apiKey` 存入 `localStorage` 并在 L88-L93 effect 同步写入。即 `api_key` **并非「仅内存」，而是明文持久化**到 webview 存储，任何能读到该存储的可执行脚本（含前述 XSS 链）均可盗取。
- 建议：默认在无 `ai_disclaimer_accepted` 时不自动持久化；或改用 Tauri `plugin stronghold` / `safeStorage` 加密后落盘；至少不在 `localStorage` 明文存储。

## 七、取消 / 资源（spawn_blocking 覆盖）

### 7.1 取消令牌有效性
- `run_background_scan`：在每个目录项开始时检查 `cancel_token`（[scanner.rs](src-tauri/src/scanner.rs#L134-L136)）且在 root 循环开头检查（L121-L124）→ **能相对及时中断**；`cancel_scan`/`cancel_ai_scan` 置位共享令牌（[scan.rs](src-tauri/src/commands/scan.rs#L335-L341)、[ai.rs](src-tauri/src/commands/ai.rs#L122-L127)）。
- `get_large_items_report`：每 1000 项检查令牌（[large.rs](src-tauri/src/commands/large.rs#L33-L46)）→ 可中断（粒度 1000，可接受）。

### 7.2 spawn_blocking 覆盖（**存在 2 处遗漏 → P2**）
| 命令 | 是否移入 spawn_blocking | 取消令牌 | 评估 |
|---|---|---|---|
| `find_duplicates` | ✅（[duplicates.rs](src-tauri/src/commands/duplicates.rs#L21)） | ❌ **无取消令牌** | 全量哈希 + rayon，不可取消，重目录下昂贵 | 
| `search_files` | ✅（[search.rs](src-tauri/src/commands/search.rs#L19)） | 结果数 1000 封顶自动终止 | 可接受 |
| `get_large_items_report` | ❌ **未包裹**（[large.rs](src-tauri/src/commands/large.rs#L15)`async fn` 内同步 WalkDir） | 有 | **阻塞 async 运行时线程池** |
| `run_background_scan` | 复用独立 OS 线程（depth-3 内 build_file_tree 同步） | 有 | 可接受 |
| `build_file_tree` | 深度 ≤3，同步在命令内执行 | — | 有界，可接受 |

- **修复建议（P2）**：
  1. `get_large_items_report` 整体套 `tauri::async_runtime::spawn_blocking`；
  2. 给 `find_duplicates` 增加 `AtomicBool` 取消令牌（与 `cancel_ai_scan` 同机制），或至少在触发新扫描时中断上一轮。

## 九、前端注入（D3 / AI 导出 HTML）

- App 内渲染：`{insight.path}`、`{insight.reason}` 等走 React JSX 转义；D3 图表均用 `.attr(...)/.text(...)`（[D3TreemapView.tsx](src/components/D3TreemapView.tsx#L240-L296)）而非 `html()` 拼接 → **App 内无 XSS（通过）**。`SponsorModal` 的 `innerHTML`（[SponsorModal.tsx](src/components/SponsorModal.tsx#L51)）为静态错误回退文案，无用户输入（通过）。

- **AI 导出 HTML（存在 XSS → P1）**：[AIInsightsView.tsx](src/components/AIInsightsView.tsx#L245-L284) `handleExport` 用**模板字符串**拼接 `<div class="path">${i.path}</div>`、`${i.reason}`、`${translatedAction}`，而 `translatedAction` 在未知 action 时**原样归还 AI 返回的 `action`**（L212）。`path` 来自真实盘符/文件名、`reason`/`action` 来自**不可信的 LLM 输出**——均未做 HTML 转义。若 AI 返回含 `<script>...` 的 reason，或文件路径含 `<`/`>`，导出并打开该 `.html` 时即执行注入脚本。
- **修复建议（P1）**：
  1. 对 `i.path`、`i.reason`、`translatedAction`（以及 `i.action`）一律做 HTML 转义（`&`→`&amp;`、`<`→`&lt;`、`>`→`&gt;`、`"`→`&quot;`、`'`→`&#39;`）；
  2. 更稳妥：改用 `document.createElement`/DOM API 或模板中不嵌入不可信字段。
