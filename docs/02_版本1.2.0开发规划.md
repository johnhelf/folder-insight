# Folder Insight 1.2.0 版本开发规划

## 1. 版本目标
本版本旨在从“单目录分析”升级为“全系统清理助手”，增强对磁盘空间的宏观掌控力，并引入 AI 辅助决策和重复文件清理功能，显著提升用户对大文件的处理效率。

## 2. 核心功能设计

### 2.1 全盘一次性分析 (Full Disk Analysis)
- **目标**：打破单盘符限制，实现一键扫描系统中所有已挂载的逻辑驱动器。
- **技术实现**：
  - **后端 (Rust)**：
    - 调用 `sysinfo::Disks::new_with_refreshed_list()` 获取所有磁盘信息。
    - 并发启动多个 `WalkDir` 任务（使用 `rayon` 或 `tokio` 任务池），每个任务对应一个盘符。
    - 统一汇总各盘符的统计结果，并通过 Tauri 事件分批推送到前端。
  - **前端 (React)**：
    - 增加“全盘扫描”入口。
    - 汇总视图：展示总空间、已用空间、剩余空间（各盘符堆叠图）。
    - 列表视图：支持按盘符分组或跨盘符按大小排序。
- **开发步骤**：
  1. 扩展 `get_disk_stats` 以支持返回所有磁盘列表。
  2. 重构 `run_background_scan` 使其支持并发扫描多个根路径。
  3. 前端 UI 适配，增加全盘汇总看板。

### 2.2 大文件/文件夹 AI 研判与建议 (AI Insights)
- **目标**：识别系统中的“巨无霸”，并结合 AI 判断其用途（系统文件、缓存、个人资料等），提供针对性的处理建议（如建议移动到非系统盘、建议通过特定软件卸载等）。
- **技术实现**：
  - **判定逻辑**：
    - 预设阈值（如 > 500MB）筛选出 Top-N 大文件。
    - 提取文件特征：后缀、所在路径关键词（如 `AppData`, `Temp`, `SteamLibrary`）、最后修改时间。
  - **AI 集成**：
    - 对接 LLM API（如 DeepSeek, OpenAI）。
    - 提示词模板：`文件路径: {path}, 大小: {size}, 后缀: {ext}, 最后修改: {time}。请判断该文件可能的用途，并给出 [建议保留/建议移动/建议压缩/建议通过官网工具卸载] 的建议及理由。`
  - **原则**：**仅提供研判建议，不执行任何写操作（删除/移动/修改）**。用户需根据建议手动在文件资源管理器中操作。
- **开发步骤**：
  1. 实现 Top-N 大文件筛选算法。
  2. 集成 HTTP 客户端（如 `reqwest`）调用 AI 服务。
  3. 设计“AI 智能分析报告”弹窗，展示研判结论。

### 2.3 重复文件搜索与发现 (Duplicate Discovery)
- **目标**：发现磁盘中内容完全相同的文件，辅助用户了解冗余分布。
- **技术实现**：
  - **三步法扫描**：
    1. **Size-Match**：按文件大小分组。
    2. **Partial-Hash**：读取头部 4KB 计算哈希。
    3. **Full-Hash**：全量哈希确认。
  - **原则**：**仅发现并展示重复项，不提供“自动清理”功能**。提供“在资源管理器中显示”按钮，由用户自行判断。
- **开发步骤**：
  1. 后端实现基于 `HashMap<u64, Vec<PathBuf>>` 的初步筛选。
  2. 实现后台异步哈希计算。
  3. 前端开发“重复项看板”，展示冗余文件的路径及占用比例。

### 2.4 1.2.0 其它高价值新功能
- **时间维度分析 (Temporal Analysis)**：
  - **“最近新增”**：快速定位最近 24 小时/ 7 天内猛增的文件（如未完成的下载、新安装的软件、自动生成的巨大日志）。
  - **“陈旧文件”**：识别一年以上未曾修改的大型文件，提示其可能是不再需要的旧备份。
- **权限与扫描完整性视图 (Permission Insight)**：
  - 许多系统文件夹（如 `System Volume Information`）无法扫描，导致“磁盘已用空间”与“扫描结果”总和不符。
  - 增加可视化反馈，展示“无法访问/权限受限”的目录分布，让用户对磁盘占用有更透明的认知。
- **全盘高级搜索与过滤 (Advanced Search & Filter)**：
  - 支持按大小范围（如 100MB-1GB）、日期范围、文件扩展名、正则表达式跨盘符搜索。
  - 支持在当前可视化视图中实时高亮搜索结果。
- **目录对比功能 (Folder Diff)**：
  - 允许用户选择两个目录，对比其结构、文件数量及大小差异。这对于检查备份的一致性或软件版本差异非常有价值。

## 3. 技术栈变动
- **Rust**：
  - `rayon`: 用于多核并发哈希计算。
  - `sha2`: 强哈希计算。
  - `reqwest`: AI API 调用。
- **Frontend**：
  - `lucide-react`: 增加更多语义化图标。

## 4. 开发排期
1. **Week 1**：全盘扫描重构与时间维度统计后端逻辑。
2. **Week 2**：重复文件搜索算法实现与权限视图可视化。
3. **Week 3**：AI 研判逻辑接入与高级搜索功能。
4. **Week 4**：整体 UI 优化、性能测试与 1.2.0 发布。
