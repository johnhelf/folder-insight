# AI分析优化需求追踪

## 任务列表

- [x] **1. 搜索提示与进度预估**
  - 搜索文件夹时的提示语修改为“正在搜索磁盘，请耐心等待”。
  - 最好给出一个进度和预估时间。

- [x] **2. 搜索中途取消**
  - 在磁盘搜索过程中，允许用户中途取消。

- [x] **3. 确认界面总大小与Token位置互换及文案修改**
  - 确认发送数据界面中，把“总大小”和“预估Token”的位置互换。
  - “总大小”改为“大文件总大小”，并注意多国语言翻译。

- [x] **4. 语言切换时同步更新预览数据**
  - 发送数据前（即预览状态），如果修改了界面语言，想要发送的 JSON 数据中的返回语言要求也应自动更新。

- [x] **5. 等待 AI 返回结果时的提示文案**
  - 确认发送之后，界面显示“正在等待AI返回结果”。
  - 提示“视数据量和AI处理速度，时间可能有长有短，请耐心等待”。

- [x] **6. 错误提示优化**
  - 如果发送失败，应当显示实际接收到的错误内容。

- [x] **7. 右侧处理意见多语言翻译**
  - 展示结果界面，右侧的处理意见（如 Delete, Archive 等）需要支持多国语言。

- [x] **8. 结果界面免责声明**
  - 结果界面增加显著声明：“结果由AI生成，未必准确，在不确定是否会对系统产生不利影响前，请及时备份数据资料再进行操作。”

- [x] **9. 导出功能优化**
  - 导出功能改为弹窗选择导出位置进行导出。
  - 导出格式改为普通的 HTML 格式，并注意排版。
  - 导出内容的语言需要与界面当前语言一致。

- [x] **10. 原始数据查看界面优化**
  - 查看原始数据界面左右宽度不一样的问题解决。
  - 右侧返回结果太窄，改成上下结构，滚动展示。
