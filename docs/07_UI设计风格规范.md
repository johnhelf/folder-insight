# 07 UI 设计风格规范（Folder Insight Design Tokens）

> 用途：作为后续前端开发的统一设计依据，避免样式漂移。
> 依据：由现有 `App.tsx`、`Header`、`TreeView`、`StatsGrid`、各视图组件实际使用的 Tailwind 类名归纳而来。
> 时间：2026-09-20

---

## 一、设计语言概述

- 定位：桌面磁盘分析工具，信息密度高、以数据可视化为核心。
- 风格：扁平 + 轻量玻璃拟态点缀；蓝色为主色；**明/暗双主题**；完整支持 **RTL**（阿拉伯语）。
- 层级：Header（白底/深灰底 + 阴影）→ 主内容卡片（圆角 + 细边框）→ 数据区域（等宽字体）。

---

## 二、色彩规范

### 2.1 主题色（Primary / Blue）
| 用途 | 明色 | 暗色 |
|---|---|---|
| 主按钮/Logo/进度条 | `blue-600` | `blue-500` |
| 图标/链接/聚焦字体 | `blue-500` | `blue-400` |
| Logo 渐变 | `from-blue-600 to-indigo-600` | `from-blue-400 to-indigo-400` |
| 强调光晕 | `shadow-blue-500/20` | `shadow-blue-500/30` |

### 2.2 功能色
| 语义 | 明色 | 暗色 |
|---|---|---|
| 危险/停止/错误 | `red-50/red-600` | `red-900/30`、`red-400` |
| 工具/AI（紫色） | `purple-50/600` | `purple-900/30`、`purple-400` |
| 赞助（粉色） | `pink-50/600` | `pink-900/20`、`pink-400` |
| 磁盘不足告警 | `text-red-500` | — |

### 2.3 背景 & 容器
| 层级 | 明色 | 暗色 |
|---|---|---|
| 页面根背景 | `bg-[#f8f9fa]` | `dark:bg-[#0f1117]` |
| Header / 卡片 | `bg-white` | `dark:bg-gray-800` |
| 表格/面板容器 | `border-gray-200` | `dark:border-gray-700` |
| 行 hover | `hover:bg-gray-100` | `dark:hover:bg-gray-800` |
| 分割线 | `border-gray-100/200` | `dark:border-gray-700/50` |

### 2.4 文字色
| 层级 | 明色 | 暗色 |
|---|---|---|
| 主文字 | `text-gray-900` | `dark:text-gray-100` |
| 次级 | `text-gray-500/600/700` | `dark:text-gray-300/400` |
| 弱化/占位 | `text-gray-400` | `dark:text-gray-500` |
| 数字/代码 | `text-gray-600/400 font-mono` | 同左 |

## 三、字体与排版

| 项 | 规范 |
|---|---|
| 正文字体 | `font-sans`（Tailwind 默认栈） |
| 数字/大小/路径 | `font-mono`，`text-xs` |
| 加粗层级 | `font-medium`（正文强调）/ `font-semibold`（标题）/ `font-bold`（Logo/主标题） |
| 标题字号 | 主标题 `text-lg/xl`；面板标题 `text-sm`；小标题 `text-xs` |
| 正文/行内字号 | `text-sm`（默认）/ `text-xs`（次要信息） |

## 四、圆角 · 间距 · 阴影

| 项 | 取值 |
|---|---|
| 卡片/面板容器 | `rounded-xl` |
| 按钮/输入 | `rounded-lg` |
| 视图切换 Tab | `rounded-md`（选中态 `bg-white rounded-md shadow-sm`） |

## 五、组件样式规范

### 5.1 主操作按钮（蓝色）
```
rounded-lg bg-blue-600 text-white shadow-sm shadow-blue-500/30 hover:bg-blue-700
```
- 内部用「分割按钮」：主动作 + `ChevronDown` 展开下拉（边框 `border-r border-blue-500/50`）。

### 5.2 危险 / 进行中按钮
```
bg-red-50 text-red-600 hover:bg-red-100（图标 animate-pulse）
暗色：dark:bg-red-900/30 dark:text-red-400 dark:hover:bg-red-900/50
```

### 5.3 下拉菜单
```
absolute top-full mt-2 w-72 bg-white dark:bg-gray-800
border border-gray-200 dark:border-gray-700 rounded-xl shadow-xl py-2 z-40/50
```
- 菜单项：`flex items-center gap-3 px-4 py-3 hover:bg-gray-50`，图标用 8×8 彩色圆底。

### 5.4 Tab 切换
```
bg-gray-100 dark:bg-gray-800 p-1 rounded-lg
选中：bg-white dark:bg-gray-700 text-blue-600 dark:text-blue-400 shadow-sm
未选：text-gray-600 hover:bg-gray-200
```

### 5.5 目录树行
- 行高 36px；hover；等宽字体显示 size/allocated/fileCount/modified。
- 受限目录红色徽标 `text-[10px] bg-red-50 border-red-100`。

### 5.6 弹窗（Modal）
- 统一由 `SponsorModal/RateModal/AboutModal` 实现，遮罩 + 居中卡片，风格与容器一致（`rounded-xl` + 边框 + 阴影）。

### 5.7 图表（Chart/Treemap）
- 图表数据经 `debouncedEChartsData`（扫描期 2s 节流、其余 100–200ms）。视觉用 `echarts`/`d3`。

## 六、动效与过渡

| 用途 | 规范 |
|---|---|
| 颜色/背景过渡 | `transition-colors duration-200` |
| 视图切换 | `AnimatePresence mode="wait"` + framer-motion（opacity/x/y/scale，0.2s） |
| 加载 | `Loader2 animate-spin`；扫描按钮 `animate-pulse` |
| 禁用态 | `opacity-50 cursor-not-allowed` |

---

## 七、RTL 与响应式

- 根节点设置 `dir={isRTL ? 'rtl' : 'ltr'}`，本地化逻辑由 `i18n.ts` 的 `isRTLLocale` 提供。
- RTL 下工具栏用 `flex-row-reverse` 翻转；箭头图标在 RTL 下用 `ChevronLeft`。
- 响应式断点：`sm/md/lg/2xl` 控制显示（如按钮文字 `hidden sm:inline`、Tab 文字 `hidden 2xl:inline`）。

---

## 八、代码实现规范（对开发者的约束）

1. **统一用 Tailwind 工具类**，禁止内联 `style`（个别动态缩进/进度宽度可视情况）。
2. **颜色一律走 2.x 节 token**，不做自定义魔法色（除页面根 `bg-[#f8f9fa]`/`#0f1117` 已在 token 表登记）。
3. **所有文案走 `t('key')`**，新增 UI 文案先更新 `en.ts`/`zh.ts` 再跑 locale 同步。
4. **新图标统一用 `lucide-react`**。
5. **明暗 + RTL 双兼容**是硬性要求，任何新组件都必须带 `dark:` 与 `isRTL` 分支。
6. 全局通用工具：`cn()`（clsx + tailwind-merge）拼接类名。

---

## 九、当前 UI 代码需治理的样式问题

1. `useAppLogic` 缩进混乱、若干 `className` 手工拼接，建议统一格式化与 `cn()`。
2. `TreeView` 头部信息密度偏高；可用空间/总大小的展示位置与 StatsGrid 有重复，建议收敛口径（同一份 `availableDisks`。
3. Tab 部分重复使用 `BarChart3` 图标（treemap 与 chart 同图标），区分度不足。
4. 弹窗/菜单 z-index、`top-full mt-2` 等叠堆写法重复出现，建议抽取 `Menu`/`Modal` 通用组件。
