## P1 · 正确性与体验（优先）

### S1 开源态基线还原与基线提交
- 文件：`src-tauri/tauri.conf.json`
- 动作：还原为开源态（identifier=com.xiaoyu.folder-insight / publisher=CN=晓宇映辰）。
- 说明：确保后续每次提交均在开源态上进行；docs/11 一并入库。
- 验证：`git status` 无敏感项；指纹扫描无商店标识。

### S2 AI API Key 存储加固（掩码 + 本地混淆）
- 文件：`src/components/AIInsightsView.tsx`
- 改动：
  - 读取回显时对已有 key 做掩码（仅显示末 4 位，如 `sk-****abcd`），避免明文长期可见。
  - 写入前用 Base64 + 固定盐做简单 Xor/obfuscate（说明仅"对抗随眼可见/日志泄漏"，非加密，密钥仍存本地）。
  - 设置面板中增加"明文显示/隐藏"切换。
- 说明：只做混淆，明确提示非加密；远期移入系统凭据管理器需跨平台评估（记录到建议，不在此轮实现）。
- 验证：重启后 key 可正常回显供调用，localStorage 中非明文。

### S3 duplicates rayon 阶段改"分块可中断"
- 文件：`src-tauri/src/commands/duplicates.rs`
- 改动：两个哈希阶段（部分哈希 / 全量哈希）从一次性 `par_iter` 改为分块迭代
  ——外层按 token（rayon 0.x 的分块迭代 / `rayon::iter::split`）处理，每处理一块检查取消令牌；命中即中止。
- 验证：取消反馈明显变快；`cargo check` 通过；人工冒烟取消。

### S4 空态 / 错误态统一
- 文件：搜索、重复文件、大文件、AI 四个视图（SearchView/DuplicatesView/LargeFilesView/AIInsightsView）+ i18n
- 改动：
  - 抽一个统一的空态组件（图标 + 主文案 + 次文案 + 可选动作按钮）。
  - 四类视图"未扫描 / 扫描中 / 结果为空 / 出错"四态文案统一、语义一致。
  - 错误态展示可操作的错误信息（含重试按钮）。
- 验证：四视图切换状态时 UI 一致不跳变；translation_check 通过。

## P2 · 数据与功能增强

### S5 文件类型视图增强（按扩展名汇总 + 展开明细，增强联动）

### S6 导出能力增强（重复文件 / 大文件报告导出 CSV / JSON）

  - 结果区显示"共 X 项（仅显示前 1000）"提示。
- 验证：tsc 通过；translation_check 通过。

### S8 AI 风险等级染色
- 文件：`src/components/AIInsightsView.tsx`
