# Folder Insight 1.2.0 详细执行计划 (Implementation Plan)

## 任务 1: 全盘扫描重构 (Full Disk Scan)
### 1.1 后端 Rust 实现
- **目标**: 修改 `get_disk_stats` 和 `run_background_scan` 支持多盘符。
- **具体步骤**:
  1. 使用 `sysinfo::Disks::new_with_refreshed_list()` 获取所有可用盘符。
  2. 修改 `AppState` 以支持管理多个并行的扫描任务（或一个汇总任务）。
  3. 使用 `rayon` 对 `WalkDir` 进行并行化处理（每个盘符一个线程）。
  4. 统一 `ProgressUpdate` 事件，增加 `disk_name` 字段以区分扫描进度。
  5. 修复 `normalize_path_string` 在 Windows 下处理根路径（如 `C:\`）的边界情况。

### 1.2 前端 React 实现
- **目标**: 增加全盘概览 UI。
- **具体步骤**:
  1. 在 `ChartView.tsx` 附近新增 `GlobalDashboard.tsx`。
  2. 使用 ECharts 实现多磁盘容量对比堆叠图。
  3. 修改侧边栏，增加“全盘分析”按钮。

## 任务 2: 重复文件发现 (Duplicate Discovery)
### 2.1 后端 Rust 实现
- **目标**: 实现高效的哈希对比算法。
- **具体步骤**:
  1. 引入 `sha2` 和 `rayon` 依赖。
  2. 实现 `find_duplicates` 命令：
     - 第一步：按文件大小（`metadata.len()`）对所有文件进行分组。
     - 第二步：对同一组的文件，读取前 4KB 计算哈希。
     - 第三步：对前两步相同的项，计算全量 SHA256。
  3. 结果返回格式：`Vec<Vec<FileNode>>`（每组重复文件为一个 Vec）。

### 2.2 前端 React 实现
- **目标**: 重复文件展示看板。
- **具体步骤**:
  1. 新增 `DuplicateView.tsx` 页面。
  2. 展示重复组列表，支持按“浪费空间总量”排序。
  3. 增加“在资源管理器中显示”按钮。

## 任务 3: AI 智能研判 (AI Insights)
### 3.1 后端 Rust 实现
- **目标**: 筛选大文件并调用 AI。
- **具体步骤**:
  1. 实现 `get_large_files_report` 命令：
     - 筛选 >500MB 的文件。
     - 提取路径、后缀、最后访问/修改时间。
  2. 集成 `reqwest` 调用 AI API（支持用户配置 API Key）。
  3. 提示词工程：严格限制输出为“建议原因”和“建议操作”。

### 3.2 前端 React 实现
- **目标**: 研判报告 UI。
- **具体步骤**:
  1. 新增 `AIReportModal.tsx`。
  2. 列表展示 AI 对每个大文件的研判结论。

## 任务 4: 其它高价值功能
### 4.1 时间维度分析 (Temporal Analysis)
- **后端**: 增加 `get_temporal_stats`，返回 `last_24h`, `last_7d`, `over_1year` 的文件集合。
- **前端**: 在 `FileTypeView` 附近增加时间分布图表。

### 4.2 权限受限视图 (Permission Insight)
- **后端**: 在 `scan_directory_structure` 报错时，记录受限目录路径。
- **前端**: 在树图中高亮显示“无法访问”的区域。

### 4.3 高级搜索与过滤 (Advanced Search)
- **后端**: 实现跨盘符正则搜索命令。
- **前端**: 增加全局搜索栏，支持 `size:>1GB` 等快捷语法。

## 5. 开发约束与原则
- **禁止写操作**: 严禁调用 `fs::remove_file`, `fs::rename` 等修改磁盘的方法。
- **性能优先**: 哈希计算必须在后台线程运行，不得阻塞主线程或 UI。
- **UI 一致性**: 沿用现有的 `lucide-react` 图标库和 Tailwind 样式。
