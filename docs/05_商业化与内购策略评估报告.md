# FolderExplorer 商业化与内购策略评估报告

本文档旨在分析 FolderExplorer 项目引入应用内购买（IAP）或高级版（Pro）机制的影响、可行功能以及开源协议调整建议。

---

## 一、 协议与开源策略调整（MIT 与 商业化）

项目目前采用 MIT 协议且完全开源。引入收费机制时，需平衡“开源精神”与“商业化保护”。

### 1. 策略选择建议

*   **策略一：Open Core（开放核心）模式（推荐）**
    *   **核心逻辑**：基础功能保留 MIT 协议并在 GitHub 开源。高级功能（Pro）的代码存放在私有仓库。
    *   **实现方式**：对外发布的安装包包含完整功能，通过 License Key 解锁高级模块。
*   **策略二：付费二进制包（Paid Binaries）**
    *   **核心逻辑**：源码 100% 保持 MIT 协议开源。
    *   **商业模式**：在官网、Microsoft Store 或 Mac App Store 提供经过签名、自动更新的“官方正式版”并收费。
    *   **适用人群**：极客可自行编译，普通用户付费购买便利性。
*   **策略三：荣誉系统 / 赞助解锁（Honor System）**
    *   **核心逻辑**：源码全开源，功能无硬性限制。
    *   **商业模式**：通过弹窗提醒或“关于”页面引导用户赞助，赞助后提供激活码移除提醒。
*   **策略四：修改开源协议（双重授权）**
    *   **核心逻辑**：从新版本开始，将协议改为 GPL 或 BSL。
    *   **商业模式**：企业用户或需要闭源使用的用户需购买商业授权。

---

## 二、 适合作为内购（Pro版）的功能

建议保持“扫描 + 基础可视化 + 基础删除”免费，将以下高价值、高开发成本的功能设为 Pro：

*   **重复文件查找与清理**：解决用户最核心的磁盘空间痛点。
*   **网络驱动器与云盘扫描**：支持 NAS (SMB/NFS)、FTP、Amazon S3 或 WebDAV。
*   **深度压缩包分析**：不解压直接透视 `.zip`, `.rar`, `.tar.gz` 内部结构。
*   **高级导出与报告生成**：支持导出 CSV、PDF、JSON 格式报告。
*   **自动化清理计划**：支持设置定时任务，自动扫描并清理临时文件。
*   **高级过滤与正则搜索**：提供多维度组合过滤（时间、大小、扩展名）及正则表达式。
*   **定制化主题与无广告**：提供更多精美 UI 主题，移除软件内的升级提醒。

## 三、 技术与社区影响分析

### 1. 技术架构影响
*   **授权状态管理**：在 `useAppLogic.ts` 中引入 `isProUser` 状态，控制 UI 锁定逻辑。
*   **验证机制**：
    *   **后端 (Rust)**：集成离线密钥验证算法（如 Ed25519）或在线支付验证。
    *   **支付平台**：推荐使用 LemonSqueezy 或 Paddle，处理全球税务。
*   **平台适配**：接入 Microsoft Store 或 Mac App Store 的 IAP API。

### 2. 社区与用户影响
*   **原则**：**绝对不要**将现有的免费基础功能变为收费。
*   **策略**：保持现有功能永久免费，通过预告新功能引导升级。为早期贡献者或老用户提供免费激活码以回馈社区。

---

## 四、 下一步行动建议

1.  **明确模式**：决定采用 Open Core 还是付费二进制模式。
2.  **平台注册**：注册 LemonSqueezy 等支付服务商。
3.  **原型开发**：
    *   在 Rust 端实现基础的非对称加密 License 验证。
    *   在 React 前端设计“关于”页面和“激活软件”弹窗。
